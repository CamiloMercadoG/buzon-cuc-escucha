# Buzón CUC Escucha

Micrositio web (solo front-end) para que los estudiantes de la Universidad de
la Costa registren sugerencias sobre bienestar, servicios, clases, inclusión,
espacios y procesos académicos.

## Tecnologías
- HTML5
- CSS3
- JavaScript

## Autor
Proyecto realizado para la asignatura Buenas Prácticas de Desarrollo de
Software.
